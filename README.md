# LimitlessInk | Payment Portal

This is the official, static landing page for **LimitlessInk** international payment instructions. It serves as a high-performance, responsive guide for clients to facilitate transactions via international remittance services to local Philippine accounts.

## Built With
- **HTML5 / CSS3**: Custom "Black, Purple, & Gold" theme.
- **JavaScript**: Frictionless clipboard integration for recipient details.
- **Inter Font Family**: For a clean, professional typeface.

## Deployment
This site is designed to be hosted on **GitHub Pages**. 
1. Push this code to your repository.
2. Go to **Settings > Pages**.
3. Select the `main` branch as the source.
4. Your portal is live at `https://<your-username>.github.io/limitless-ink-portal/`

## Security & Privacy
This is a static site. No payment data is processed on-site. It functions purely as an instruction set for third-party remittance services (Remitly, WorldRemit, Wise) to ensure secure delivery to **Maya Philippines**.
